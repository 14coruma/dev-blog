This week I prototyped tile-based movement and combat features. 

I am taking a composition over inheritance approach for these 
systems. I may discuss this more in a future post, but in
short, composition helps decouple classes from their implementations. This
improves maintainability and makes it easier to change out implementations 
as the project grows.

## Movement
The player and enemies take turns moving on a tile based grid.
To implement this, each moveable object instantiates a `GridMovement` behavior.
The `GridMovement` class processes commands to move objects on the grid,
checking for potential obstacles that prevent movement.
The animation for movement is handled by moving the parent towards the `GridMovement`
object in the `Update()` loop.

```csharp
transformToMove.position = Vector3.MoveTowards(transformToMove.position, movePoint.position, moveSpeed * Time.deltaTime);
```

## Combat
To prototype basic combat behavior I created two abstract behaviors:
`KillableBehavior` and `AttackBehavior`.
By implementing these two behaviors and adding them to a Unity `MonoBehavior`,
I am able to give objects the ability to both attack and be killed in a scene.
The implementations themselves (e.g. `MeleeAttackBehavior`) can worry about the details of things such as
 health and strength.

```csharp
public abstract class KillableBehavior : MonoBehaviour
{
    public abstract void Damage(int damage);
    public abstract void Kill();
}
```

```csharp
public abstract class AttackBehavior
{
    public abstract void Attack(KillableBehavior killable);
    public abstract bool AttackLeft();
    public abstract bool AttackRight();
    public abstract bool AttackUp();
    public abstract bool AttackDown();
}
```

Then to give these behaviors to an existing `MonoBehavior`, all I need to do is

```csharp
public class PlayerController : MonoBehaviour
{
    public MoveableBehavior moveableBehavior;
    private AttackBehavior attackBehavior;
    private KillableBehavior killableBehavior;
    ...
    void Start()
    {
        // Initialize Behaviors
        moveableBehavior ??= GridMovement.InitializeBehavior(transform);
        attackBehavior ??= new MeleeAttackBehavior(gameObject, 10, true);
        killableBehavior ??= BasicKillableBehavior.InitializeBehavior(gameObject, 60, true);
    }
    ...
}
```
